# Getting started

Welcome to **GitCrook**. This page covers *installing*, ~~guessing~~ configuring and `running` it.
Read the [quickstart](./quickstart.md) or the [docs][d] next.

## Install

1. Clone the repository
2. Run `pnpm install`
3. Start it with `pnpm dev`

### Requirements

- Node 22 or newer
- PostgreSQL
  - version 15 or newer
- [x] Docker (optional)
- [ ] A domain name
